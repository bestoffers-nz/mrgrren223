MR GREEN - RENDER CORE PHP PACKAGE

1. Deploy this folder as a Docker Web Service on Render.
2. Replace https://dailysource.online/ in index.php and go.php if your final destination changes.
3. Replace YOUR-SITE.onrender.com in robots.txt and sitemap.xml with the real Render hostname.
4. index.php displays the landing page and then automatically redirects after 2 seconds.
5. gclid, gbraid, wbraid, gad_source, gad_campaignid and UTM parameters are preserved.
6. The automatic redirect behavior is the same for all requests. This package does not detect or exempt bots, crawlers, AdsBot, reviewers, IP ranges, headless browsers, or fingerprints.
